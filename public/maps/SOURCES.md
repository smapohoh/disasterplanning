Retrieved 2026-11-12 from one small-area OSM API map extract:
https://api.openstreetmap.org/api/0.6/map?bbox=127.0385,37.5420,127.0450,37.5475

`seoul-forest.json` contains road, building, water and park geometries with selected names/tags. The JSON itself is distributed in this repository and served at /maps/seoul-forest.json. Map presentation is separate from the underlying ODbL data. The meeting marker is a prototype example, not an OSM verified shelter or entrance.
